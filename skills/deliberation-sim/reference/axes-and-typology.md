# 価値軸・課題類型・争いの三分類

人格生成の材料。領域を問わず使えるよう、入口を汎用に取り、専門領域では下位軸へ分解する。

---

## 手順1 — 課題の5類型

汎用性はここで確保する。あらゆる決定は次のどれかに落ち、類型ごとに立ち上がる緊張が違う。

| 類型 | 問いの形 | 典型的な緊張 |
|---|---|---|
| 実行判断型 | Xをやるか、やらないか | 期待利益 ⇄ リスク・不可逆性 |
| 選択型 | A案かB案か | 各案が最適化している価値の非互換 |
| 配分型 | 限られた資源を誰に | 公平 ⇄ 効率 ⇄ 必要度 |
| 是正型 | 問題が起きた、どうするか | 責任の所在 ⇄ 再発防止 ⇄ 関係の修復 |
| 規範設定型 | ルールを作るか、どう作るか | 予測可能性 ⇄ 個別事情への柔軟性 |

---

## 手順2 — 利害の地図

課題文から機械的に抽出する。

| 枠 | 問い |
|---|---|
| 便益 | 誰が得るか |
| 費用 | 誰が負うか |
| リスク | 誰が負うか |
| 実行の手間 | 誰が負うか |
| 撤回権限 | 誰が決定を覆せるか |

**便益とリスクの担い手がずれているとき、そこが最大の争点。** 全部が同一人物なら利害の対立がなく、人格の対立は価値ではなく**確率評価の相違**から生じる（投資判断がこの型）。

---

## 手順3 — 汎用9軸

| 軸 | 守ろうとするもの |
|---|---|
| 自律・自己決定 | 本人が決めること自体 |
| 危害の回避 | 最悪の結果の大きさ |
| 公正・分配 | 誰が何をどれだけ得るかの釣り合い |
| 効率・費用対効果 | 投入に対する見返り |
| 手続きと約束の遵守 | ルールが守られること自体 |
| 長期の持続可能性 | 将来にわたって続くこと |
| 実行可能性・現場負荷 | 実際に回るかどうか |
| 信頼と関係の維持 | 関係が壊れないこと |
| 可逆性 | 後戻りできる余地 |

**この課題で実際に互いを削り合っている軸を3〜5本だけ選ぶ。** 全部使うのは失敗。緊張していない軸を持った人格は、議論に参加せず賛同するだけの置物になる。

### 専門領域での下位分解

9軸は入口であって終点ではない。専門領域に入ると領域固有の下位軸へ分解される。

- **法律**：法的安定性・形式的権利 ／ 具体的妥当性 ／ 制度趣旨 ／ 文言忠実 ⇄ 意思解釈 ／ 立証可能性
- **投資**：期待リターン ／ 最大損失 ／ 分割可能性 ／ 構造的持続性 ／ 認識可能性（自分が知り得ることの限界）
- **福祉**：本人の意思 ／ 安全 ／ 制度適合 ／ 財務 ／ 職員負担 ／ 家族との関係 ／ 他利用者との公平

上位軸で人格を組んでみて対立が薄いと感じたら、下位分解を試みる。

---

## 手順4 — 人格の組み方

選んだ軸に2つの座標を掛ける。

- **時間**：短期（今期・当面）／ 長期（数年後・次の担当者）
- **立場**：実行する側 ／ 受ける側 ／ 第三者

同じ「効率」軸でも、短期×実行者と長期×受け手では正反対の結論が出る。**賛成同士が別理由になる構造がこの掛け算から自動的に生まれる**ので、意図して作り込む必要がない。

---

## 手順5 — 不在の当事者

影響を受けるのに議論の席にいない者を必ず1名入れる。

- 将来の担当者／次の世代
- 当事者本人
- 少数側
- 供給連鎖や資金の流れの最終端にいる者
- 制度そのもの

**常設枠とする。** 実施2例のいずれでも議論の転回点を作った。相続事例では遺言解釈という主軸の着想源になり、投資事例では最も強気な人格を折る役を果たした。内輪の合理性で議論が閉じるのを構造的に防ぐ、最も効く装置である。

不在の当事者は立場（賛成／反対）を持たない。**問いを投げる役**に徹する。

---

## 争いの三分類

R0で各争点にラベルを付ける。ここを間違えると議論が空転する。

| 種別 | 内容 | 扱い |
|---|---|---|
| **事実** | 調べれば確定する | 議論を中断し、調査タスクへ落とす |
| **不確実性** | 同じ事実を見て確率評価が割れる。将来予測を含む | **調べても議論でも決まらない。「いつ、何を見れば決着するか」への変換だけができる** |
| **価値** | 何を優先するか | 決定権者本人が引き受ける |

真ん中の層は当初の設計になかった。相続事例では全争点が事実か価値に落ちたが、将来予測を含む課題ではここが主戦場になる。

**この層に対する議論の唯一の成果は、観測点の特定である。** 「2027年の設備投資が二桁増を維持するか」のように、どちらが正しかったと後から判定できる形にまで落とす。落とせないなら、その争いは議論の対象から外す。

### 二大時間浪費

この分別を明記すると防げる。

- 調べれば済んだのに延々議論した
- 決めるしかないのに調査を口実に先送りした
