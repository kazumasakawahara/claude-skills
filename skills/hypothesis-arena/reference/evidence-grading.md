# 証拠の重みづけと確信度更新の規約

擁護者・裁定者が証拠を提示・評価する際の共通通貨。特に薬理・医学系の問いでは本規約の適用を必須とする。

## 階層ラベル

| ラベル | 内容 | 目安の重み |
|---|---|---|
| M | メタ分析・系統的レビュー | 最重 |
| R | RCT（無作為化比較試験） | 重 |
| O | 観察研究（コホート・症例対照） | 中 |
| C | 症例報告・症例集積 | 軽 |
| E | 専門家意見・総説の主張部分 | 最軽 |
| 机 | 機序研究・動物実験・in vitro | **仮説生成には重、仮説決着には最軽** |

## 修飾子（ラベルに付記して重みを増減する）

- `+rep` 独立追試あり ／ `-rep` 追試失敗・追試なし
- `-coi` 利益相反あり（製薬企業資金・著者の立場）
- `-n` 小標本 ／ `+n` 大規模
- `-pub` 出版バイアスの兆候（funnel plot 非対称・登録済み未発表試験の存在）
- `-sel` 選択バイアス・交絡の指摘が既にある

例：`R -coi -n` は名目上RCTでも実質 O 相当まで割り引く。GRADE の発想（研究デザインで開始し、バイアス・非一貫性・非直接性・不精確・出版バイアスで格下げ、効果量・用量反応で格上げ）に準じる。

## 禁じ手

1. **機序の物語による階層飛ばし。** `机` の証拠がどれだけ精緻でも、それだけで M/R と対等に扱わない。「メカニズムが説明できる」は「効果が実証された」の代替ではない。ユーザーの問題意識（検証なき増薬の悪循環）は、まさにこの飛ばしの産物であることを常に想起する。
2. **階層の逆用。** 「RCTがないから効果はない」も誤り。証拠の不在と不在の証拠を区別し、「未検証」と正確に記載する。
3. **単一研究の切り札化。** どの階層でも、単一研究を決着とせず追試状況を必ず確認する。
4. **要旨だけの引用。** 判別読書リストで高殺傷力とされた文献は、要旨でなく方法と限界の節まで確認したことを証拠エントリに明記する。

## 確信度更新の運用

- 確信度は 0–100 の整数。厳密なベイズ計算は求めないが、**ベイズ的規律**を課す：
  - 更新は必ず台帳の証拠エントリを参照する（エントリなき更新は無効）。
  - 事前に驚くべき証拠（自説の予測に反する）ほど大きく動かす。予測どおりの証拠で大きく上げない（確証は安い）。
  - 1回の更新で ±20 超は、自滅条件の成立または M/R 階層の証拠がある場合のみ。
- **複数仮説の合計は 100 に縛らない**（残余仮説・未知の説明の余地を認める）。ただし首位仮説が 90 を超えるときは「残り 10 は何か」を言語化させる。
- 更新履歴は `40→55(E-02)→70(E-05)` の形式で証拠エントリIDつきで台帳に残す。なぜ変わったかが後から監査できることが、演出的更新の唯一の防波堤である。

## 哲学・法学系の問いへの適用

実証階層が使えない概念判別層では、代わりに論証の強度ラベルを使う：

| ラベル | 内容 |
|---|---|
| 証明 | 前提を認める限り帰結が必然（演繹的） |
| 強 | 直観の大勢と体系整合性の双方が支持 |
| 中 | 直観か整合性の一方のみが支持、または有力な反例が併存 |
| 弱 | 可能性の指摘にとどまる |

修飾子として `-前提` （争いのある前提に依存）を付す。文献判別層の M〜机 と混用しない。
