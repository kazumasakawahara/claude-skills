# 実行例（要約版）

フェーズの雰囲気を掴むための短縮ウォークスルー。実運用ではもっと丁寧に行う。

## 例1（機序＋文献判別）：抗精神病薬の長期投与はドーパミン過感受性を介して転帰を悪化させうるか

**手順0**：「悪化」の操作的定義を「長期（2年以上）の症状・機能転帰」に固定（急性期の再発抑制効果は争点から除外——ここを混ぜると言語的論争になる）。判別層の仮判定：機序＋文献の混在。

**H0 仮説カード**（ユーザー承認済みと仮定）：
- H1 過感受性説（擁護者：機構論者）——長期遮断がD2受容体の up-regulation を生み、離脱時悪化と耐性を招く
- H2 自然経過説（擁護者：懐疑主義者）——非服薬群の良好な転帰は軽症例が服薬を止められただけ（逆因果・選択バイアス）
- H3 用量依存説（擁護者：折衷的実証主義者）——高用量・多剤でのみ過感受性が問題化し、最小有効量では利益が上回る

**H1 立論の抜粋**：
- H1 の文献予測【未読・予測】：離脱を漸減で行った試験では急激中断より再発率が低いはずだ（過感受性なら離脱速度が効く）
- H1 の自滅条件：漸減・急断で再発率に差がない質の高い比較が確認されたら重傷
- H2 の自滅条件：ベースライン重症度を統制した解析でなお非服薬群の転帰が良ければ重傷

**H3 判別読書リストの抜粋**：
```
[D-01] 減薬速度と再発率を比較した系統的レビューの有無と結論
       殺傷力: H1の中核予測を直接検定。なければH1は【未検証】に留まる
[D-02] Harrow/Wunderink系の長期追跡での重症度統制の方法と批判の応酬
       殺傷力: 統制が頑健ならH2重傷、脆弱ならH2が優勢に
[D-03] 用量反応データ（最小有効量研究）の転帰指標
       殺傷力: 閾値効果が確認されればH3浮上
```

**規約の効きどころ**：H1 擁護者が動物実験の受容体密度データ（`机`）だけで確信度 80 を主張 → 裁定者が evidence-grading.md 禁じ手1で差し戻し。「機構は仮説の資格であって決着ではない。D-01 を先に消化せよ」。

## 例2（概念判別）：クオリアは物理的事実に還元できるか

**手順0**：「還元」の操作的定義を固定（存在論的還元か、説明の還元か——ここで既に二つの問いに分裂することが判明。前者を主戦場に選択）。判別層：概念。

**H0 仮説カード**：
- H1 還元的物理主義（擁護者：体系整合論者）
- H2 性質二元論（擁護者：直観尊重論者）
- H3 現象概念戦略（擁護者：概念分析家）——存在論は物理一元、説明ギャップは概念の特殊性の産物

**H2 相互攻撃の抜粋**：H2 がマリーの部屋を提示 → H1 が steelman を承認したうえで「知識の獲得は能力知であって事実知でない」と応答 → 裁定者は論証強度を双方「中 `-前提`」と査定（「知識」の分類という争いのある前提に依存）。

**H3 判別課題**：概念層なので読書リストは「決着」でなく**条件の地図**を作るために出す。
```
[D-01] 現象概念戦略への標準的反論（Chalmers のマスター論証）とその応答の現状
       殺傷力: H3が反論を処理できなければH3後退、できればH1-H3連合が優勢
```

**出口**：3セッション後、裁定者が判別不能（型：過小決定＋前提選択）を宣言。「物理主義的前提を採るなら H3、直観の証拠能力を認めるなら H2」という条件付き地図を決着サマリとして台帳に残す。**一本の勝者を宣言しないことが正しい終わり方**である例。

## 反面教師：やってはいけない進行

- 仮説2本だけで開始 → H1 への反対が自動的に H2 への賛成と誤読される偽の二分法。3本目（選択バイアス説など）を必ず探す。
- 「関連しそうな文献を10本読んでから考えましょう」→ 殺傷力の設計がない読書は確証バイアスの燃料。読む前に判別リストを作る。
- 再開セッションで台帳を読まずに記憶で続行 → 確信度履歴が監査不能になり、演出的更新の温床になる。
